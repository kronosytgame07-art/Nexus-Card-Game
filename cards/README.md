# Illustrations de cartes

Dépose ici les images générées, nommées exactement `{id-de-la-carte}.png`
(voir `src/engine/cards.ts` pour la liste des ids, ou `docs/ART_PROMPTS.md`
pour le prompt complet à donner à un générateur d'images).

Format recommandé : PNG, cadrage portrait ~3:4, au moins 1024×1365 px.
Tant qu'un fichier n'existe pas, l'interface affiche automatiquement le dos
de carte générique à la place (aucune image cassée).
